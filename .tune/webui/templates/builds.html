A subject is an (AOTriton tag, ROCm) pair. ROCm comes from perfmon::default_rocm in workers.db: {% if perfmon_rocm %}{{ perfmon_rocm }}{% else %}not set{% endif %}. Only the head tag is buildable today; historical release subjects additionally need that release's kernel image tarball.
