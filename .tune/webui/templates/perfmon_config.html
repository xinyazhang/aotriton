Perfmon Configuration

Settings for the performance-measurement workload. These live in workers.db under the perfmon:: key prefix, not in config.rc.

Default ROCm Version

The ROCm the perfmon image is built against, and the runtime half of every subject. A subject is an (AOTriton tag, ROCm) pair identified as aotriton-<tag>+rocm<version>, so this string is not just a build input — it labels the published numbers.

Give the exact version the wheel index expects — 7.14.0, or a TheRock pre-release such as 7.14.0a20260624. A truncated 7.14 is rejected: it goes verbatim into pip install "rocm[...]==<version>", so a loose value either fails the install or mislabels a build.

Leave empty and save to clear it. While unset, the Build Perfmon Artifacts section on the Builds tab stays disabled — the version is never defaulted, because guessing it would mislabel whatever gets built.
